# 📝 fastNote

> Минималистичный блокнот с автоматической нумерацией, встроенным калькулятором и автосохранением каждые 10 секунд.  
> Создан на **Python (Tkinter)**. Идеально подходит для быстрых заметок, списков дел и расчётов на лету.

---

## 🚀 Возможности

✅ **Авто-нумерация строк**  
После ввода `1.` и нажатия **Enter** следующая строка создаётся автоматически как `2.`, `3.` и т.д.  

✅ **Встроенный мини-калькулятор**  
Пиши прямо в строке, например:
2 + 2 =
и увидишь подсказку с результатом. Нажми **TAB**, чтобы вставить ответ.  

✅ **Автосохранение**  
Текст сохраняется каждые 10 секунд в `autosave.txt` — ничего не потеряется.  

✅ **Открытие и сохранение файлов**  
Можно быстро открывать `.txt` и сохранять свои заметки через диалоговое окно.  

✅ **Тёмная эстетика**  
Спокойная палитра:  
`#1e1e1e`, `#222526`, `#00ff88` — приятная для глаз при ночной работе.
